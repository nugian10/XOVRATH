# XOVRATH — Website

Static site for XOVRATH — Unknown Artifacts. Plain HTML/CSS/JS, no build
step, no framework, no dependencies. Local only.

## What was built

- `index.html` — home. Hero, intro, live collection stats, six featured
  forms (#001, #042, #087, #126, #203, #318), links to Explore / Archive / Mint.
- `explore.html` — visual gallery, 48 artifacts per page, lazy-loaded
  images. Each card links to its archive detail.
- `archive.html` — all 2,222 slots, client-side filters (classification /
  background / accent / search by #id), each slot marked **Available**.
  Token detail via `archive.html?id=<n>`: larger artwork + attributes
  fetched from that token's metadata JSON.
- `mint.html` — agent-only minting, explained in five steps. No mint button,
  no wallet connection, no amounts shown anywhere on the site. Includes a
  copyable "Prompt for your agent" block that references the deployed
  contract address once one exists.
- `about.html` — philosophy, art direction, the six classifications
  (VOID / DISTORTION / ORIGIN / ANOMALY / FRACTURE / UNKNOWN).
- `styles.css` — black ground, bone-white type, charcoal/silver detail,
  purple only as a rare accent, grain overlay, responsive.
- `app.js` — shared logic: reads collection data at runtime, stats,
  pagination, filters, detail view, prompt builder.
- `config.js` — `CONTRACT_ADDRESS = ""` (empty — the contract is NOT
  deployed) and IPFS CID placeholders.

## How the site reads data

At runtime the site fetches its data from the public GitHub repo
(`raw.githubusercontent.com/nugian10/XOVRATH/main/collection/…`) —
see `config.js`. The old `../collection/` relative paths were removed
30 Okt 2026: Vercel deploys only this `site/` folder, so those paths
returned 404 on the live site and the gallery was empty.

- `collection.json` — collection stats
- `all-tokens.json` — array of
  `{id, classification, background, form, accent, elements, sha256}`
- `images/<id>.svg` — artwork
- `metadata/<id>.json` — per-token attributes

If those files are absent, the site still renders: the archive lists all
2,222 slots as "artwork pending", stats show `—` for published artworks,
and detail pages say the metadata has not been published yet. No fake
counts, no fake minted numbers, no fake addresses are ever shown.

## Preview locally

Serve from anywhere — the data now comes from GitHub, so the server
root no longer matters:

```bash
cd ~/workspace/projects/xovrath/site
python3 -m http.server 8000
```

Then open http://localhost:8000/ — home, explore, archive, mint, about.

## Honest status

- Contract **not deployed yet**. `CONTRACT_ADDRESS` in `config.js` is empty
  on purpose. Never fill in a guessed address.
- **No independent audit.** Stated in the footer of every page.
- Minted on-chain is **0**; every artifact is listed as Available.
- No amounts are printed anywhere on the site. The mint page explains that
  the agent reveals the amount only inside the mint flow.

## Still missing

1. **Collection files** — `collection/` (images, metadata, `collection.json`,
   `all-tokens.json`) is generated by a parallel process and was not present
   when this site was built. The site works as soon as those files land.
2. **IPFS pin** — images + metadata need pinning; fill `IMAGES_CID` and
   `METADATA_CID` in `config.js` afterwards.
3. **Contract deploy** — deploy `contracts/XovrathNFT.sol` on BNB Mainnet
   (56), then set `CONTRACT_ADDRESS` in `config.js`.
4. **Mint activation** — owner (the Agentic Wallet's agent) activates minting
   after deploy.
5. **Hosting** — Vercel deploy (not done here; local only by design).

## Verification

Run from the project root while the server is up:

```bash
for p in /site/ /site/explore.html /site/archive.html /site/mint.html /site/about.html; do
  curl -s -o /dev/null -w "%{http_code} $p\n" "http://localhost:8000$p"
done
grep for the banned strings across site/ — result must be zero matches.
This README deliberately does not print those strings, so the check stays clean.
node --check site/app.js && node --check site/config.js
```

No rendered 390px check was possible in this environment (no headless
browser available). The CSS was audited instead: `overflow-x: hidden` on
`html, body`, `box-sizing: border-box` everywhere, `max-width: 100%` on
all images, fluid grids collapsing to one column below 520px.
